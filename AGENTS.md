# Reglas para trabajar en este proyecto

Estas reglas se siguen siempre, en cada conversación.

- Háblame en español y explícame lo que haces con palabras simples. No sé programar.
- Antes de escribir código, hazme preguntas y propón un plan corto. Espera a que lo apruebe.
- Pídeme permiso antes de instalar programas o borrar archivos.
- Haz una app web simple con HTML, CSS y JavaScript, que se vea bien en el celular.
- Cuando termines algo, dime exactamente cómo abrirlo y probarlo en mi navegador.
